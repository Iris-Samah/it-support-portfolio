# IT Support Portfolio

Welcome to my IT Support Portfolio!

This repository showcases eight projects completed as part of my journey to develop practical technical skills and build a strong foundation in IT Support and Help Desk operations.

The projects demonstrate troubleshooting, system diagnostics, technical documentation, problem-solving, and user support.

## About Me

I am an Information Technology student with an HND in Information and Communication Technology (ICT), currently pursuing a BSc in Information Technology.

I have completed the Cisco Networking Academy IT Support course and am continuously developing my technical knowledge and practical skills.

I am particularly interested in IT Support, Help Desk Operations, Network Troubleshooting, and Technical Support.

My goal is to build a career in IT Support by applying my knowledge, gaining practical experience, and continuously learning new technologies.

## Portfolio Projects

### 1. Windows Troubleshooting
- Explored Windows system settings and diagnostic tools.
- Practised identifying and investigating common Windows issues.
- Documented troubleshooting findings.

### 2. Network Troubleshooting
- Used Windows command-line tools to investigate network connectivity.
- Practised commands such as ipconfig, ping, and nslookup.
- Tested connectivity between devices and external network destinations.

### 3. Software Installation and Troubleshooting
- Practised software installation and troubleshooting procedures.
- Explored application-related issues and basic troubleshooting techniques.

### 4. User Account Management
- Explored Windows user account settings.
- Practised basic account management and user administration concepts.

### 5. Help Desk Ticket Management
- Created an Excel-based help desk ticket register.
- Organised support requests by ticket ID, priority, and status.
- Used dropdown lists, conditional formatting, filters, and dashboard formulas to track tickets.

### 6. Microsoft Office Troubleshooting
- Tested Microsoft Word, Excel, and PowerPoint.
- Created and saved sample files.
- Checked application functionality and investigated basic troubleshooting considerations.

### 7. Printer and Peripheral Troubleshooting
- Inspected printer and peripheral settings in Windows.
- Tested Microsoft Print to PDF.
- Examined Bluetooth, USB, camera, microphone, and speaker functionality.

### 8. Final Help Desk Simulation
- Completed a simulated help desk support scenario involving a Wi-Fi connectivity issue.
- Followed a structured troubleshooting process.
- Used diagnostic commands to investigate the issue.
- Verified the simulated resolution and documented the support ticket.

**Note:** The final help desk scenario was a simulation designed to demonstrate troubleshooting and support procedures.
